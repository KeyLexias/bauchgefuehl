# Icon-Alternativen

Nicht verwendete Entwürfe für das App-Icon. Aktiv ist `icons/icon.svg`.

- `ocker-bisher.svg`: bisheriges Icon
- `klassisch.svg`: bisheriges Symbol in Grün mit Plus-Abzeichen
- `gefuellt.svg`: gefüllte Form mit ausgestanztem Plus
- `pixel.svg`: Pixel-Stil

Zum Wechseln die Datei nach `icons/icon.svg` kopieren und die PNG-Größen neu erzeugen
(512, 192, 180 für `apple-touch-icon.png`).
